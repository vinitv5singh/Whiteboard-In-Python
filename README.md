🎨 Project Title:
"AI-Enhanced Smart Whiteboard with Sentiment & Drawing Intelligence"

📄 Project Description:
This project is a Python-based interactive AI Whiteboard Application built with Tkinter that allows users to draw freely on a canvas while integrating simple artificial intelligence features. 
Users can take notes alongside their drawings, and the application can analyze the sentiment of the notes using TextBlob. 
Based on the keywords in the notes (e.g., "sun", "tree", "house"), the system can auto-suggest and draw simple shapes on the canvas to support creative expression. This combination of drawing tools and basic AI capabilities offers an engaging way for users to visualize thoughts and explore ideas interactively.

An interactive whiteboard application built with Python's `Tkinter` GUI toolkit that combines **drawing tools**, **note-taking**, and **AI features** such as **sentiment analysis**, **keyword-based drawing suggestions**, and more.

---

## 🚀 Features

- ✏️ **Freehand Drawing**: Use the mouse to draw on a canvas with customizable color and line width.
- 📝 **Note-Taking Panel**: Add text-based notes or ideas alongside the canvas.
- 💬 **Sentiment Analysis**: Analyze the emotional tone of your notes (Positive, Negative, Neutral) using `TextBlob`.
- 🎯 **AI Drawing Suggestions**: Based on the content of your notes (keywords like "sun", "tree", "house"), auto-generate simple drawings on the canvas.
- 🎨 **Color & Line Control**: Choose your pen color and adjust line width using sliders.

---

## 🖼️ Demo

> Example use:  
> 1. Draw freely on the canvas  
> 2. Type `"I love sunny days"` in the notes section  
> 3. Click "Analyze Sentiment" → Output: **Positive**  
> 4. Click "Suggest Drawing" → A sun is drawn!
